# Empire

Juego de estrategia web y móvil inspirado en Social Empires: reino leveleable, mapa explorable con recursos, dragones y otras criaturas, ejércitos y fortalezas, y ataques entre reinos.

## Contenido

- `prototipo/index.html`: prototipo jugable en un solo archivo. Ábrelo en el navegador.
- `docs/diseno.md`: documento de diseño (bucle de juego, recursos, edificios, unidades, progresión, PvP asíncrono).
- `docs/stack.md`: stack técnico recomendado (TypeScript, Phaser 3, Capacitor, Node y PostgreSQL).
